Troubleshooting Display Issues

1. Set XFrameOptionsMode to ALLOWALL

If your app appears blank, Google may be blocking iframe embedding. Ensure your doGet() includes:

function doGet(e) {
  return HtmlService.createHtmlOutputFromFile('Index')
    .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL);
}

2. Verify Access Permissions

Ensure your deployment access is set to Anyone, or open it directly using the external link icon in the top-right corner.

Instant Android App Install Available

Creates a standalone WebAPK on your home screen immediately.

Option 1: Instant Android WebAPK (No PC Needed) Fastest
  1. Host this HTML file on any free HTTPS host (e.g., GitHub Pages, Netlify, or Vercel).
  2. Open that hosted link in Google Chrome on your Android phone.
  3. Tap the ⋮ (Three Dots) menu → Add to Home screen → Install. Android automatically compiles and installs it as a real app!
Option 2: Download a Standalone .APK File Shareable File

To get a physical .apk file you can send via WhatsApp or install offline:

  1. Host this file online (or use your direct Apps Script URL below).
  2. Go to PWABuilder.com (by Microsoft) or WebIntoApp.com.
  3. Paste the URL, customize your app icon/name, and click Package for Android to download your signed .apk file.
